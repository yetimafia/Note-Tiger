Rules data used by the character builder and sheets.

- `spells-srd.json`: spell names, levels, class lists, casting times, ranges and components from the System Reference
  Documents (SRD 5.1 for the 2014 rules, SRD 5.2 for the 2024 rules) by Wizards of the Coast LLC, licensed under
  CC-BY-4.0 (https://creativecommons.org/licenses/by/4.0/). Compiled from the 5e-database project
  (https://github.com/5e-bits/5e-database, MIT). Spells from other books aren't included; type those in.
- `sheet-dnd-2024-official.json`: which box of the official 2024 D&D character sheet PDF gets what. The sheet itself
  isn't included; add your own copy in Library → Character sheets.
