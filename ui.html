🏛 Council several local AIs vote

      
Run the same work on several local AIs (this PC and/or other PCs on your home network running Ollama) and combine
        their answers. Different model families make different mistakes, so the vote catches more of them. With 0 or 1 members it's off and
        Note Tiger works as usual. Members on different PCs work at the same time; members on the same PC take turns.

      
The council is for the free local AI. With Claude selected it's off.

      

      

        
        
        
        
      

      
      

        
        
      

      

        

          

        

          

        

          

      

      
The judge keeps only what at least two drafts agree on, leaning on the GM's narration. If a member is off, asleep
        or too slow (one answer taking longer than the timeout), it's skipped and the rest carry on; if nobody answers, this PC does it alone.
        On another PC, start Ollama with OLLAMA_HOST=0.0.0.0 and allow port 11434 through its firewall.

    

    

      
Table talk

      
      
The AI tags conversation that isn't about the game (real life, other games, food…). It stays in the transcript, dimmed, and can still make Best Lines, but the recap and questions only use the game.

    


    

      
Opening recap

      
      
If you start by recapping last session, the AI finds where that ends and keeps it out of the new recap (it stays in the transcript, tagged). Most reliable: the GM types /session begin when play starts.

🌐 Player website

      
Publishes every session to a free website (GitHub Pages) so players can read recaps and color-coded transcripts on any device. Everything is encrypted with the group password, so only people who know it can read anything.

      
      

        
        
        
Where the website lives (it uses its own gh-pages branch). Your Note-Tiger repo works.

        
        
        
Create a fine-grained token: Repository access → Only select repositories → your repo; Permissions → Contents: Read and write and Pages: Read and write. Leave empty to keep the saved one.

        
        
        
What players type to open the site. At least 8 characters; a few words is best (e.g. redmond barrens chummer). Changing it re-encrypts everything, and the old password stops working.

        
        
The password is hidden behind a spoiler (click to reveal). Anyone who can see your recap channel can read it.

        

          
          
        

      

    


    

      
🔤 Spelling

      
Speech recognition mangles names ("wren rocky" for Renraku). Note Tiger fixes them in transcripts and recaps using Shadowrun names, your runners, contacts and places, plus anything you add here. Changes apply to old sessions too.

      
      
      
      
      
      
      

      

      
Saved right away, no restart needed.

    


    

      
💾 Backups

      
Copies your sessions, contacts, loose ends and settings to a private GitHub repository: the day after anything changes, after each session, and at least once a week. Your tokens and passwords are never included. On a new PC, set this up again and click Restore.

      
      

        
        
        
On GitHub: create a new repository, name it e.g. note-tiger-backup, choose Private. Note Tiger refuses to back up to a public one.

        
        
        
Leave empty to use the website token above. Either way, the token needs access to the backup repository: edit your token → Repository access → add the backup repository; Permissions → Contents: Read and write.

        

          
          
          
        

      

    


    

      
🎲 Game night

      
A few hours before game night, Note Tiger privately messages whoever has the GM role a prep note: where you left off, threads to pull, who might show up, things the players may have forgotten, and a few hook ideas. The GM can also get it any time with /campaign prep.

      
      

        

        

        

      

      
Uses this computer's clock, and Note Tiger has to be running then. The GM needs to allow direct messages from server members.

      

    


    

      
🚨 Alerts

      
The bot sends you a Discord DM if it crashes, if nothing has been heard for 15 minutes while people are in the voice channel, or if a recap fails. It messages the bot's owner (you, in the Discord Developer Portal) unless you put someone else's user ID below.
