Table talk

      
      
The AI tags conversation that isn't about the game (real life, other games, food…). It stays in the transcript, dimmed, and can still make Best Lines, but the recap and questions only use the game.

    


    

      
Opening recap

      
      
If you start by recapping last session, the AI finds where that ends and keeps it out of the new recap (it stays in the transcript, tagged). Most reliable: the GM types /session begin when play starts.

🌐 Player website

      
Publishes every session to a free website (GitHub Pages) so players can read recaps and color-coded transcripts on any device. Everything is encrypted with the group password, so only people who know it can read anything.

      
      

        
        
        
Where the website lives (it uses its own gh-pages branch). Your Note-Tiger repo works.

        
        
        
Create a fine-grained token: Repository access → Only select repositories → your repo; Permissions → Contents: Read and write and Pages: Read and write. Leave empty to keep the saved one.

        
        
        
What players type to open the site. At least 8 characters; a few words is best (e.g. redmond barrens chummer). Changing it re-encrypts everything, and the old password stops working.

        
        
The password is hidden behind a spoiler (click to reveal). Anyone who can see your recap channel can read it.
